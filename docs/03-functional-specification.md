## 画面仕様

本アプリは単一画面（タスク一覧 + 追加フォーム）で構成する。

### タスク管理画面（`/`）

| 領域 | 表示項目 | 操作 |
|------|----------|------|
| ヘッダー | アプリ名・残タスク数 | - |
| 追加フォーム（`TaskForm`） | タイトル入力欄・追加ボタン | 入力 → 送信でタスク追加（F-1） |
| タスク一覧（`TaskList` / `TaskItem`） | チェックボックス・タイトル・削除ボタン | 完了トグル（F-3）・削除（F-4） |
| 空状態 | 「タスクがありません」 | - |

#### バリデーション表示

- 空 / 空白のみ / 200 文字超 → 追加ボタン押下時にエラーメッセージを表示し、送信しない。
- サーバエラー（5xx）時はトースト等で失敗を通知する。

#### `data-testid` 方針（E2E 用）

主要要素に安定セレクタを付与する（[`08`](./08-test-specification.md) の E2E から参照）:

| 要素 | data-testid |
|------|-------------|
| タイトル入力欄 | `task-input` |
| 追加ボタン | `task-submit` |
| タスク行 | `task-item` |
| 完了チェック | `task-toggle` |
| 削除ボタン | `task-delete` |
| 空状態 | `task-empty` |

## 画面遷移

単一画面のため画面間遷移はなし。状態遷移のみ:

```
[空状態] --追加--> [一覧(1件以上)] --全削除--> [空状態]
                      |  ^
                 完了トグル / 削除（同一画面で再描画）
```

## UI/UX 方針

### 全体方針

- TailwindCSS v4 で**簡素・読みやすい**レイアウト（中央寄せの単一カラム）。デザインの作り込みは目的外。
- 操作は即時にサーバ反映し、一覧へ反映する（楽観更新は必須としない。実装時に確定）。
- レスポンシブは最小限（モバイル幅でも崩れない程度）。
