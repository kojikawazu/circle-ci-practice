## 機能要件

| ID | 機能名 | 概要 |
|----|--------|------|
| F-1 | タスク追加 | タイトルを入力してタスクを新規作成する |
| F-2 | タスク一覧 | 登録済みタスクを作成日時順に一覧表示する |
| F-3 | 完了トグル | タスクの完了 / 未完了を切り替える |
| F-4 | タスク削除 | タスクを削除する |
| F-5 | 永続化 | タスクを PostgreSQL に保存し、リロード後も保持する |

### F-1: タスク追加

- フォームにタイトルを入力し送信するとタスクが作成される。
- 空タイトル・空白のみ・長すぎるタイトルは拒否する（バリデーションは [`06`](./06-security-specification.md) 参照）。
- 作成後、入力欄はクリアされ、一覧に即時反映される。

### F-2: タスク一覧

- `created_at` の昇順（または降順、実装時に確定）で一覧表示する。
- 各タスクはタイトル・完了状態・操作（完了トグル / 削除）を持つ。
- 0 件のときは空状態メッセージを表示する。

### F-3: 完了トグル

- チェック操作で `completed` を反転し、サーバへ反映する。
- 完了タスクは視覚的に区別する（取り消し線など）。

### F-4: タスク削除

- 削除操作で該当タスクをサーバから削除し、一覧からも除去する。

### F-5: 永続化

- すべての変更は `server/api` 経由で PostgreSQL に保存される。
- ブラウザをリロードしてもタスクが保持される（E2E で検証 → [`08`](./08-test-specification.md)）。

## データ項目

詳細なスキーマは [`05-data-specification.md`](./05-data-specification.md) を参照。

| 項目 | 必須 | 制約 |
|------|------|------|
| title | ✓ | 1〜200 文字。前後空白はトリム。空白のみ不可 |
| completed | - | 真偽値。既定 `false` |
| id | （自動） | UUID。サーバ生成 |
| createdAt | （自動） | タイムスタンプ。サーバ生成 |

## 受け入れ条件

- [ ] タイトルを入力して追加すると、一覧に新しいタスクが表示される。
- [ ] 空 / 空白のみのタイトルでは追加できず、エラーが分かる。
- [ ] 完了トグルで状態が切り替わり、見た目が変わる。
- [ ] 削除でタスクが一覧から消える。
- [ ] リロード後もタスク（と完了状態）が保持されている。
- [ ] 上記が UT（ロジック）と E2E（実 Postgres）で自動検証され、CircleCI で緑になる。
